# Talent Intelligence Platform

Build one local-first Next.js App Router application in TypeScript with Tailwind CSS, Prisma and SQLite. Keep all application logic in this app: no separate backend, vector database, Redis, queues, Docker, or custom cryptography.

Use a maintained authentication library compatible with the installed stack. Extract PDF text in the Node runtime. Real AI features must call the configured provider for text generation and embeddings, and semantic matching must use cosine similarity. Never substitute unavailable AI credentials with fake successful AI output; expose the blocked state instead.

Prioritize the final demo: Backend Developer (Python, Django, PostgreSQL, Docker), three PDF applications, evidence-based ranking, human shortlist, interview questions, scheduling, and a dashboard update.
